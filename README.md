## 🌐 Free 1-Click Hosting Guide

### Deploying with GitHub Pages:
1. Create a new GitHub repository named `neha-portfolio`.
2. Push these files to your repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/<your-username>/neha-portfolio.git
   git push -u origin main
   ```
3. Go to **Settings > Pages > Branch: main > Save**.
4. Your website will be live in 1 minute at:
   `https://<your-username>.github.io/neha-portfolio/`
